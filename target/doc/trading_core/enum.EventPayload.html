pub const fn required_schema_version(&self) -> u16

The minimum journal schema version this payload requires.

Venue-bearing payloads need version 3; everything else may be written as version 1. Journal::append rejects a body that understates this, so a venue-bearing record can never be written as a legacy body. Fill provenance (version 2) is decided by the engine’s record meta, not by the payload, because legacy journals are still replayable.

Source

pub const fn carries_venue_contract(&self) -> bool

Whether the payload serializes an order intent or a quote, i.e. the contracts that carry a venue in schema version 3.
