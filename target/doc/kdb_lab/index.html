Checked-in KDB-X analytics contract for Nirnay.

This crate does not reimplement market analytics in Rust. It owns the typed input and output contracts around the checked-in q script analytics/kdb/mbp_metrics.q and drives a locally installed KDB-X engine. A differential reference computes the same arithmetic in Rust. D11 retired the synthetic golden corpus; no checked-in golden is consumed.

The KDB-X path is a research/statistics surface. Price and spread values are f64 observations in the input unit (rupees as exported by upstox-decode-export); they are not the authoritative money types used by the trading domain. One book is analysed per source; sources are never merged or summed.
