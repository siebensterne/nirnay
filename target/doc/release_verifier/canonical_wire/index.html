Module canonical_wire 

Source
Expand description

Independent strict types for the canonical NDC v2 Profile 1 wire schema.

This module is a consumer-side implementation of the language-independent authority WS-NDC-2026-11-24-003 and the versioned schema package ndc-v2-schema-profile-1. It imports no Fieldbook code and shares no validator or serializer. The types below are strict: unknown members, missing required members, wrong JSON types, implicit coercions, duplicate members and non-canonical numeric forms are refused.

Neither these types nor the older internal crate::schema types are normative. into_internal_manifest and into_internal_record are explicit mappings from the canonical wire representation into the existing internal representation. Byte-derived ordering is recomputed from received record bytes in derive_key_from_bytes; no caller-supplied key is trusted independently of those bytes.
