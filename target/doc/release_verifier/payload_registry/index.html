Module payload_registry 

Source
Expand description

Locally trusted, immutable per-event payload schema registry for D6.

The ratified contract declares per-event payload schemas in the release manifest. Those declarations are untrusted bytes. This module keeps the authoritative registry outside the release: the caller installs local material, stage five verifies its digest, and every canonical record is then checked against the installed binding before it is admitted.

The Workspace ratification names no schema language. Adopting JSON Schema would add a dependency and a new contract, so this implementation selects an explicit local structural validator driven by registry metadata: nirnay-structural-payload-v1 with validator identity structural-v1. That validator checks object members, scalar kinds, required fields, duplicates and scalar grammar for the canonical record payload. JSON Schema adoption requires a separate Workspace amendment; no such dependency is added here and D6 is not reduced to event-type membership.
