pub struct ReleaseVerifier { /* private fields */ }
Expand description

An independent verifier for NDC v2 release packages.

Profile selection is resolved locally inside the bounded streaming path. The removed test-only opt-in cannot be reached from a production API:

ⓘ
use release_verifier::ReleaseVerifier;
let verifier: ReleaseVerifier = todo!();
let _ = verifier.with_test_only_profiles();

pub fn with_payload_schema_registry(self, input: PayloadRegistryInput) -> Self

Install a locally trusted payload schema registry for canonical wire mode.

The material is supplied out of band. No schema byte is read from the release package. Digest, version, schema bytes and validator identity are verified when stage five loads it; a failure is a typed stage-five refusal and no admission receipt is issued.

pub fn verify_release( &self, locator: &ReleaseLocator, request: &AdmissionRequest, ) -> Result<AdmissionReceipt, VerifierError>

Verify a release through the LEGACY_BUFFERED path and issue a receipt.

LEGACY_BUFFERED classification: this entry point keeps its caller-owned resource policy and its buffered stage-five reader. It is retained for existing callers and does not dispatch to verify_release_streaming. A streaming refusal is not retried here, so no buffered fallback can turn a streaming rejection into an admission. This wrapper exposes the first refusal. Callers that also need the cleanup result use verify_release_with_diagnostics.

Source

pub fn verify_release_with_diagnostics( &self, locator: &ReleaseLocator, request: &AdmissionRequest, ) -> Result<AdmissionReceipt, RefusalDiagnostic>

Verify a LEGACY_BUFFERED release and keep cleanup beside a refusal.

LEGACY_BUFFERED classification: this entry point is the buffered reader with caller-owned policy. Its signature and behavior stay stable. It is not a fallback for verify_release_streaming; a streaming failure stops at its own first refusal with no receipt.

pub fn verify_release_streaming( &self, locator: &ReleaseLocator, request: &AdmissionRequest, ) -> Result<AdmissionReceipt, RefusalDiagnostic>

Verify a release through the ratified bounded streaming path.

The trusted local resolver supplies the profile selection before any source is opened. An empty approved registry returns a typed NoApprovedProfile refusal. No producer declaration can raise a local allowance. The twelve stages, first refusal and cleanup contract are unchanged. This entry point is the only streaming path; the two existing public verifiers keep their signatures and their caller-policy behavior as LEGACY_BUFFERED. A refusal here returns directly; it is not retried through either buffered verifier.
