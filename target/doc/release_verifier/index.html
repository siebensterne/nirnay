Independent Nirnay verifier for immutable NDC v2 release packages.

This crate is a separate implementation. It imports no Fieldbook code, owns no signing key and creates no shared validator. It contacts no provider and contains no market observation. Test data is abstract structured JSON with official JCS and Ed25519 vectors only.

Verification is twelve ordered stages. The first refusal stops processing; no later stage softens an earlier failure and a rejected release is never partially consumed. Published files are opened with O_NOFOLLOW below a configured trusted root, hashed from the opened descriptor, copied into a caller-provided private staging directory and sealed before any downstream stage runs. A receipt records checks performed and is not a right.

Entry-point classification: verify_release_streaming is the bounded streaming path. verify_release and verify_release_with_diagnostics are LEGACY_BUFFERED, keep their caller-owned policy and remain for existing callers. A streaming refusal returns to its caller; the buffered verifiers are not fallback paths and a rejection is not retried through them.
