Module profile_resolver 

Source
Expand description

Trusted local resolution of approved resource profiles.

This module is the only path from a profile declaration to an enforcement limit. The approved registry is held here, not supplied by the caller of the streaming verifier. No production profile is registered: with an empty registry the resolver refuses with ProfileError::NoApprovedProfile before a release directory or any source is opened. Finite TEST_ONLY bindings are constructed only inside cfg(test); they carry no production authority.

Resolution rechecks the role binding, canonical digest and approved version of each entry. No numeric limit is invented or registered by this module; the local ceiling is derived from the approved role profiles themselves.
