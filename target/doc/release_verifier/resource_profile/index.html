Module resource_profile 

Source
Expand description

Normative, immutable ResourceProfile contract for bounded streaming.

This module implements the form ratified in engineering/decisions/WS-STREAM-001-b15-b16-architecture-ratification.md section 3. It defines a contract, not an approved instance: no production digest, numeric maximum, codec identifier or capability state is registered here. Every field of ResourceProfile and ProfileLimits is private and populated by a crate-private validating constructor. The two profile handles are opaque to external callers; selection runs through the trusted local resolver in crate::profile_resolver, which holds the approved registry. Finite TEST_ONLY profiles exist only inside cfg(test) builds and carry no production authority.

Effective limits are the stricter-of combination of a trusted local ceiling, the selected role profile and a producer declaration when one is present. A producer declaration can lower an allowance but never raise it.
