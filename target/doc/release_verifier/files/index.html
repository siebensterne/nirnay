Source
Expand description

Trusted release-root access and private snapshot sealing.

Directory descent uses descriptor-relative openat with O_NOFOLLOW. The configured root itself is opened with O_NOFOLLOW | O_DIRECTORY through the standard library’s safe OpenOptionsExt. Files are hashed from the opened descriptor and copied into a caller-provided private staging directory before any downstream stage runs. No stage after sealing reopens a published path.
