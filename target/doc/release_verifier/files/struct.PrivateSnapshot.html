pub fn verify_entry(&self, name: &str) -> Result<EntryProof, VerifierError>

Re-verify one sealed entry from its descriptor without materializing bytes.

The entry must carry a verified state from finalize_entry. The copy is reopened with O_NOFOLLOW relative to the sealed staging descriptor and streamed through an incremental SHA-256 in fixed profile-sized chunks.

pub fn discard(&self) -> Result<CleanupReport, CleanupPending>

Remove staged files after a refusal and prove the directory is empty.

Every removal error is reported. A successful result is returned only after a post-removal directory sync and an empty re-enumeration.
