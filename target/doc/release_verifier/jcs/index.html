RFC 8785 JSON Canonicalization Scheme for the independent verifier.

This module is a stand-alone implementation. It shares no serializer with the producer. Input is a serde_json::Value produced by the strict parser in crate::schema, so duplicate member names, NaN, Infinity and lone surrogates have already been refused before canonicalization.
