Decode an immutable Upstox raw-frame JSONL journal into full V3 JSON.

This is an offline research preparation tool. It validates each RawFrame, decodes the original protobuf bytes, and preserves capture timestamps, local sequence and source frame SHA-256. It never connects to a broker.

The journal is read through the shared bounded JournalReader so record limits, torn-tail detection and EOF semantics match the recorder and the rest of the archive. A completed, verified capture session is required: the manifest hash, frame count and terminal status are checked before and after decoding. Output is published only after every check succeeds.
