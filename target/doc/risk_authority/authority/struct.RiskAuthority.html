Struct RiskAuthority

pub struct RiskAuthority { /* private fields */ }
Expand description

The authorization boundary. Shareable across threads; all state transitions are serialized internally.

pub fn new( account_id: AccountId, policy: ValidatedRiskPolicy, instruments: Vec<Instrument>, trade_date: TradeDate, ) -> Self

Build an authority with validated policy and owned effective-dated reference data. No order, OMS, broker or live dependency. Without a control store the kill switch stays in memory and defaults engaged.

Build an authority that loads and persists kill-switch state through control. An absent or unreadable control record fails closed engaged.

Authored kill-switch decision from the registered operator owner. The control store is fsynced before the in-memory flag changes, so a crash between the two resolves to engaged on replay. Releasing an engaged switch additionally requires a non-empty release_evidence_ref.

Risk-reducing path. It is observation-free by design so positions can be flattened when health is degraded; accounting invariants remain fail-closed. See invariant L5.

Risk-reducing path: convert a reservation into a filled position. Observation-free by design so fills can always be accounted for, even when the feed is stale or the kill switch is engaged (L5).
