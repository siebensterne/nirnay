Token-ready, read-only Upstox Analytics API smoke test.

This binary checks Historical Candle V3, Full Market Quote V3 and Market Data Feed V3. WebSocket protobuf frames are archived byte-for-byte; this smoke test does not normalize them or claim historical tick replay.
