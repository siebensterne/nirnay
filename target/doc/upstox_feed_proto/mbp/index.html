Module mbp 

Source
Expand description

Typed five-level MBP projection from Upstox V3 Full frames.

Upstox publishes Quote.bidP/askP as IEEE-754 doubles. Nirnay enters its financial model only in exact integer paise. The conversion rule here is explicit: rupees × 100, rounded half away from zero, with non-finite, negative and out-of-range values rejected. Provider double precision is the source limitation; this module does not add a second one.
