Conformance executable for the canonical NDC v2 Profile 1 wire mapping.

The binary reads a release directory containing canonical wire documents, runs the twelve-stage release verifier against that directory and writes a stage-by-stage diagnostic. It uses an injected test-only trusted publisher entry whose public key is derived from the fixed conformance seed [0x11; 32]; no private key material, release key, provider contact or market observation is present in this executable.

Rights remain UNKNOWN under the current freeze. The injected rights evaluator therefore returns Unknown unconditionally. The expected result is a first refusal at the rights-admission stage after the structural, manifest, signature, artifact and byte-derived-ordering stages pass. No admission receipt is created and no private snapshot survives the refusal.
