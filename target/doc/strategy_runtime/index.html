M2.3 deterministic Rust strategy runtime.

Executes only frozen, validated artifacts. Strategies emit intents through a narrow interface; they never access cash, OMS, risk, broker state or live routing. Python remains the research environment and supplies golden-vector parity fixtures for the rational arithmetic.
