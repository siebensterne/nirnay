Module archive 

Source
Expand description

Content-addressed archive for original exchange source bytes.

Normal open fails closed on a torn manifest; repair is an explicit operation that quarantines damaged bytes and writes a report. Object bytes are verified against their manifest hash and reads and writes are bounded.
