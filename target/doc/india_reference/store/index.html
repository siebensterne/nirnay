india_reference

Module store 

Source
Expand description

Durable reference identity allocation and immutable revision publication.

Identity and aliases are persisted in the same transaction. SQLite uses WAL, synchronous=FULL, foreign keys and a bounded busy timeout. Revision publication enforces an expected parent and an idempotency key.
