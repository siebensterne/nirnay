Bounded India exchange reference-data ingestion.

This crate uses india-domain as the canonical model. It owns source parsing, explicit row outcomes, opaque instrument identity allocation and reconciliation. It does not duplicate Instrument, Listing, Isin, TickAssignment or SourceProvenance.
