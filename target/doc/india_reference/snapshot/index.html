Expand description

Versioned reference snapshot payload and its domain rules.

This module is pure data and validation: no filesystem and no database IO. It is the foundation of the promoted P1-04 reference-store contract. The encoded envelope bytes are authoritative for payload_sha256; the semantic hash covers only the fields that affect a decision, never capture metadata.

encode_payload
Encode the authoritative payload bytes. The caller stores these bytes verbatim and checksums them; decoding never reconstructs them.
latest_states_at
Resolve the listing states visible at (t_valid, t_recorded) from the HEAD snapshot only. Earlier revisions are never concatenated: a correction supersedes the state it replaces. For each (instrument, venue, valid_from) the latest knowledge at or before t_recorded wins; per (instrument, venue) the interval with the greatest valid_from covering t_valid is returned. Results are in canonical order and contain no duplicates.
