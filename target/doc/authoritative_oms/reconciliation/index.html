Module reconciliation 

Source
Expand description

Independent OMS-vs-ledger reconciliation.

The comparator recomputes positions and order aggregates from both durable sources instead of trusting either summary. It classifies every delivery anomaly in the M3.5.3 matrix and emits the typed [ReconciliationReport] consumed by the risk authority. A missing view or a digest failure is Unavailable, which blocks new risk exactly like Mismatch.
