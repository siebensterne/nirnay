Module account_projection 

Source
Expand description

Deterministic account projection from durable OMS fill events.

The projector is the only writer of the account ledger derived from OMS executions. It lives in the engines layer (a legal downward dependency on storage); account-journal itself stays a generic append-only primitive. Every posting is content-addressed, so duplicate delivery is a no-op and a reused execution id with different content is a hard conflict. Corrections are always new reversing records; history is never rewritten.
