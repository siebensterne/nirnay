authoritative_oms

Module store 

Source
Expand description

The single authoritative OMS store: an append-only commit journal that persists the complete order, attempt/outbox and event state after every successful transition. One append + sync_all is the atomic commit point; replay requires a contiguous sequence chain, so a truncated or corrupt tail is refused rather than silently accepted.
