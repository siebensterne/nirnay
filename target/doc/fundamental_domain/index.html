Corporate financial facts with explicit provenance and point-in-time semantics.

This crate is pure by design: it performs no filesystem, network, database, clock, broker or exchange operations. Untrusted wire records are deserialized into typed values and must pass FinancialFact::validate before use.

A reported value is not interchangeable with a derived value. A revision is append-only and names the revision it supersedes. Historical selection requires both a known publication timestamp and a committed ingestion timestamp.
