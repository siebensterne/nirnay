Source
Expand description

Run a deterministic paper session from an immutable PIT dataset.

This binary is an application adapter, not a new execution engine. It reads canonical MarketEvent rows, converts them to exact trading-core quote types, emits one operator-configured strategy intent, and drives the public PaperEngine API. The engine owns risk, order lifecycle and the account journal. No broker SDK or live routing is involved.
