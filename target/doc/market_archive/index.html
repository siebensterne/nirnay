Crate market_archive 

Source
Expand description

Deterministic primitives for the raw market-data archive.

This crate does not connect to a provider and does not claim data rights. Provider adapters must pass original payload bytes and a reference to the account’s applicable entitlement. A raw frame is not a normalized event.
