Expand description

The permit body: everything the issuer signs. Excludes signatures and attestations (those sign this digest).

pub fn canonical_payload(&self) -> Result<Vec<u8>, PolicyError>

Versioned, unambiguous canonical encoding: ENCODING_VERSION byte, then length-prefixed fields. Empty strings and embedded NULs are representable without ambiguity. The byte layout is unchanged from v2 for every representable value; only the fallible timestamp conversion differs (previously saturated, now denied).
