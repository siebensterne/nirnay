M2.7 operating-environment primitives for the paper/shadow runtime.

This crate validates a filesystem layout that keeps evidence out of the source tree, produces digest-verified backups with verified fresh-path restore, and evaluates operational health into a gate on new risk. It does not deploy anything, contact a broker or authorize live trading.
