5//! Independent Nirnay verifier for immutable NDC v2 release packages.
6//!
7//! This crate is a separate implementation. It imports no Fieldbook code, owns
8//! no signing key and creates no shared validator. It contacts no provider and
9//! contains no market observation. Test data is abstract structured JSON with
10//! official JCS and Ed25519 vectors only.
11//!
12//! Verification is twelve ordered stages. The first refusal stops processing;
13//! no later stage softens an earlier failure and a rejected release is never
14//! partially consumed. Published files are opened with `O_NOFOLLOW` below a
15//! configured trusted root, hashed from the opened descriptor, copied into a
16//! caller-provided private staging directory and sealed before any downstream
17//! stage runs. A receipt records checks performed and is not a right.
18//!
19//! Entry-point classification: `verify_release_streaming` is the bounded
20//! streaming path. `verify_release` and `verify_release_with_diagnostics` are
21//! LEGACY_BUFFERED, keep their caller-owned policy and remain for existing
22//! callers. A streaming refusal returns to its caller; the buffered verifiers
23//! are not fallback paths and a rejection is not retried through them.
