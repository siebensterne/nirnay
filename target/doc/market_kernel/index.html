Crate market_kernel 

Source
Expand description

M2.2 market-data kernel projection.

Consumes verified source observations and produces canonical kernel events through the M2.1 identity contract. The kernel applies per-stream continuity and is deterministic: the same verified session yields the same events in a fresh process. No provider decoding, broker, order or trading behavior lives here; the raw journal remains the evidence authority upstream.
