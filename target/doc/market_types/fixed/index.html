Exact decimal parsing and rescaling for exchange wire values.

The SBE challenge schema represents both dollars and contract counts as signed 64-bit integers scaled by 1,000,000. Exchange APIs publish decimal strings with venue-specific precision, and non-prediction instruments need arbitrary scales and signed prices. All conversion therefore goes through a configured scale here, using i128 intermediates and checked conversions. Nothing is rounded silently: an inexact conversion is an error.
