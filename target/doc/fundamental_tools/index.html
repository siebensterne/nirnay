Bounded JSONL validation for immutable fundamental datasets.

The validator does not fetch, scrape, normalize or publish source documents. It checks company identity and financial fact contracts, revisions, lineage, strict line framing, record limits and the exact input-byte digest. The validator retains typed records in memory for cross-record graph validation; production-scale ingestion requires a durable indexed store and is out of scope.
