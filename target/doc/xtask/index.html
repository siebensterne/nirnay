Repository task runner: a typed, discoverable CLI over the project gates.

The task set is a clap subcommand enum: one source of truth for names, help text and delegation. Every gate runs through Cmd with an explicit argument vector — never a shell — and its exit status is propagated so CI sees the gate’s own result. The first failing step stops the run; nothing is skipped silently.
